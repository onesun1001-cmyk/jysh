# 방명록 연결 방법 (약 5분)

방명록 글은 본인 구글 계정의 **구글 시트**에 저장됩니다. 별도 서버나 비밀 키는 없습니다.

1. https://sheets.new 에서 새 시트를 만들고 이름을 정합니다(예: `jysh 방명록`).
2. 메뉴 **확장 프로그램 → Apps Script** 를 엽니다.
3. 기본 코드를 지우고 `tools/guestbook-apps-script.gs` 내용을 통째로 붙여넣은 뒤 저장합니다.
4. 오른쪽 위 **배포 → 새 배포** → 유형 **웹 앱**
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **모든 사용자**
5. 권한 승인 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/…/exec`)을 복사합니다.
6. `index.html` 의 `CONFIG.guestbookUrl` 에 붙여넣고 커밋·푸시합니다.

## 관리
- 글 숨기기: 시트의 D열(hide)에 아무 글자나 적으면 목록에서 빠집니다. 행을 지워도 됩니다.
- 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정 → 새 버전** 으로 다시 배포해야 반영됩니다.
- 예식 후 방명록을 닫으려면 배포를 보관 처리하거나 `guestbookUrl` 을 비우면 됩니다.

## 참고
- 웹 앱 URL은 공개되어도 되는 주소입니다(시트 자체는 비공개 유지). 다만 누구나 글을 쓸 수 있는 주소이므로
  이름 20자·내용 300자 제한, 분당 등록 한도, 봇 차단용 숨은 칸을 넣어 두었습니다.
